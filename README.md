# 164 OFFICIAL WEB SITE

HTML / CSS / JavaScript だけで作られた静的サイトです。

---

## 📁 ファイルの役割

```
164_HP/
├── index.html          ページの中身（文章の骨組み）
├── css/style.css       見た目・デザイン
├── js/main.js          データを読み込んで表示する処理
├── data/
│   ├── news.json       ★ News を更新するファイル
│   └── songs.json      ★ 楽曲を更新するファイル
└── assets/logo.png     ロゴ画像
```

**普段の更新で触るのは `data/` の中の2つだけです。**

---

## 🖥 手元で確認する方法

1. ターミナルを開く
2. このフォルダに移動する（`cd ` と入力したあと、フォルダをターミナルにドラッグ＆ドロップすると楽です）

   ```bash
   cd ~/164_HP
   ```

3. サーバーを起動する

   ```bash
   python3 -m http.server 8000
   ```

4. ブラウザで <http://localhost:8000> を開く
5. 終わるときはターミナルで `Ctrl` + `C`

> **なぜ index.html をダブルクリックではダメ？**
> ブラウザの安全機能により、ファイルを直接開いた状態では
> JSONファイルの読み込みがブロックされ、News と 楽曲が表示されません。
> 必ず上の手順でサーバー経由で開いてください。

## 📝 News を追加する

`data/news.json` を開いて、`[` のすぐ下に次のかたまりを追加します。

```json
  {
    "date": "2026-08-01",
    "category": "LIVE",
    "title": "ここにタイトル",
    "body": "ここに本文。\n改行したいところに \\n と書きます。",
    "links": [
      { "label": "公式サイト", "url": "https://example.com/" }
    ]
  },
```

### ルール

| 項目 | 書き方 |
|---|---|
| `date` | `"2026-08-01"` の形（年-月-日、必ず2桁）。**日付が分からないときは `"2026-08"` と月まででOK**（`2026.08` と表示されます） |
| `category` | `LIVE` / `RELEASE` / `MEDIA` / `INFO` のどれか |
| `title` | 一覧に表示される見出し |
| `body` | 開いたときに出る本文。改行は `\n` |
| `links` | ボタンになるリンク。無いときは `[]` |

### 注意点

- **日付順に並べ替えは自動**なので、どこに書き足してもOKです
- かたまりとかたまりの間には **カンマ `,`** が必要です
- **一番最後のかたまりの後ろにはカンマを付けない**でください
- 本文に `"`（ダブルクォート）を使いたいときは `\"` と書きます

## 🎵 楽曲を追加する

`data/songs.json` に追加します。

```json
  {
    "title": "曲名",
    "videoId": "2-zPY0vrpjQ",
    "year": "2011"
  },
```

`videoId` は YouTube の URL の最後の部分です。

```
https://youtu.be/2-zPY0vrpjQ
                 ~~~~~~~~~~~ ← ここ

https://www.youtube.com/watch?v=2-zPY0vrpjQ
                                ~~~~~~~~~~~ ← ここ
```

サムネイル画像は videoId から自動で取得されます。
`year` は空 `""` にすると表示されません。

---

## ⚠️ 書き換えたら必ず確認

JSON はカンマ1つ抜けただけで表示されなくなります。
書き換えたあと、ターミナルでこれを実行すると文法チェックができます。

```bash
python3 -m json.tool data/news.json > /dev/null && echo OK
```

`OK` と出れば大丈夫です。エラーが出たら、表示された行番号のあたりを見直してください。

## 🎨 色を変えたい

`css/style.css` の一番上にある `:root { ... }` の中を書き換えます。

```css
--bg:         #0a0a0b;       /* 背景 */
--text:       #ececee;       /* 文字 */
--accent:     #e8342c;       /* 差し色（赤） */
--accent-dk:  #b31f18;       /* 濃いめの赤（ボタンの背景など） */
--accent-rgb: 232, 52, 44;   /* ↑と同じ色を R, G, B で書いたもの */
```

> ⚠️ `--accent` を変えたら **`--accent-rgb` も同じ色に合わせてください**。
> 半透明の表現（ロゴ背景のグロー、タグの下地など）はこちらを使っています。

## 🔤 書体について

| 変数 | 書体 | 使う場所 |
|---|---|---|
| `--font-display` | **Anton** | 大きい見出し（NEWS / PROFILE など） |
| `--font-en` | **Oswald** | メニュー・日付・ボタンなど小さい英字 |
| `--font-ja` | **Noto Sans JP** | 日本語の本文 |

見出しに Anton を使っているのは、**ロゴの「164」と字間の詰まり具合を揃えるため**です。
ロゴを実測したところ「1」と「6」のすきまは文字高さの約4%で、
Oswaldでは字間を詰めても3倍以上開いてしまい、無理に詰めると文字同士がくっついてしまいます。
Anton は書体自体の字幅が狭いため、字間を調整しなくてもロゴとほぼ同じ詰まり具合になります。

> ⚠️ Anton は **太さが400しかありません**。
> `font-weight: 600` などを指定するとブラウザが無理やり太らせて字形が崩れるため、
> 見出しには `font-weight: 400` を指定しています。

## 🖼 ロゴ画像について

`assets/` には2つのロゴが入っています。

| ファイル | 用途 |
|---|---|
| `logo-mark.png` | **ページ内のロゴ**（背景を透明にした版） |
| `logo.png` | ファビコン・SNSシェア画像（黒背景のオリジナル） |

ページ内で黒背景版を使うと、サイトの背景との境目が四角く見えてしまうため、
背景を透過させた `logo-mark.png` を別に用意しています。
